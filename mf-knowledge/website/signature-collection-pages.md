# Overview

The eight "signature" fabric collections each have a dedicated editorial `/pages/` story. They were
rebuilt one at a time (with client review of each) — replacing baked-in icon images with clean SVG
icon strips, removing disabled leftover sections, shrinking oversized images, restructuring the flow
and adding a closing "Speak to a specialist" CTA.

# Bespoke sections built

- `fabric-spec-icons` — light credential icon strip (the shared base, reused across the redesign).
- `process-timeline` — vertical exploded production timeline (PEEL).
- `fabric-anatomy` — animated exploded fabric cross-section (Mediflex, Electra).
- `palette-forest` — editorial colour-story tiles (Amazónia, Electra).
- `decor-motif` — transparent-PNG motif that peeks from the page edge (Amazónia jaguar & toucan).

# Per-page highlights

- **CHANCE** — baked icon photo replaced with separate homepage-style icons.
- **PEEL** — icons image removed; catalogue button added; off-brand "Production Stages" reworked as the dynamic `process-timeline`.
- **STRAW** — mid-page video moved into the hero (overlay text kept); icons swapped; "special thanks" section improved.
- **ORIGIN** — two icon images replaced; structural reorder (why → how → look → where → act); oversized media shrunk.
- **Amazónia** — full editorial "monograph" rebuild with the forest palette and the jaguar/toucan edge motifs.
- **Mediflex / Electra** — `fabric-anatomy` exploded cross-section; Electra's colours shown as a shoppable palette.
- **Siesta & Patio** — two-collection structure clarified; outdoor performance icon strip.

# Status

Built and previewable on the sandbox; under client review via the Notion Page Review tracker.
