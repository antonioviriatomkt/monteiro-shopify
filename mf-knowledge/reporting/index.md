# Reporting

Monteiro's marketing **reporting infrastructure** — the dashboard Viriato builds and runs to report
to Ivana, kept as evidence of work done. Each file is one concept; the file path is its identity.
Chronological detail lives in the [reporting log](/reporting/log.md).

Types used here: `Initiative`, `Change`.

# Initiative

* [Marketing Dashboard](/reporting/marketing-dashboard.md) - Monteiro-branded Next.js/Supabase/Notion web app that replaces the monthly PDF report; GA4 · Search Console · Shopify · Sender pulls live, deployed on Vercel.
