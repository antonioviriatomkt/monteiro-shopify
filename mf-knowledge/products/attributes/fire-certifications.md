# Overview

Monteiro coated fabrics are tested against a broad set of international **flammability /
reaction-to-fire** standards. The full set below mirrors the **Flammability** filter on
monteirofabrics.com. All of these are fire-performance standards — they cover ignitability,
reaction-to-fire classification, and sector-specific fire tests (furniture, marine, transport,
aviation). The exact certifications held **vary by collection** — always confirm per product.

# Standards

| Standard | Region / use | What it certifies |
|----------|--------------|-------------------|
| FMVSS302 | USA — automotive | Flammability (horizontal burn rate) of motor-vehicle interior materials |
| EN 1021 Part 1 & 2 | EU — furniture | Ignitability of upholstered furniture: cigarette (Part 1) & match flame (Part 2) |
| NF P92-503 (M1) | France | Reaction to fire (electric-burner test); **M1** = non-flammable class |
| NF P92-507 (M2) | France | Fire classification of furnishing materials; **M2** class |
| BS 5852 Crib 5 | UK — contract seating | Ignitability of upholstered seating, ignition source **crib 5** (severe contract) |
| BS 5852 Crib 7 | UK — high-risk | Ignitability, ignition source **crib 7** (highest, high-risk environments) |
| IMO 2010 FTP Code Part 8 | International — marine | Fire Test Procedures Code, Part 8 — upholstered furniture for ships |
| DIN 4102 (B1) | Germany — building | Fire behaviour of building materials; **B1** = flame-retardant (schwerentflammbar) |
| UNI 9175 Class 1.IM | Italy — furniture | Reaction to fire of upholstered furniture; **class 1.IM** (best) |
| UNI 9175 Class 3.IM | Italy — furniture | Reaction to fire of upholstered furniture; **class 3.IM** |
| UN ECE R118 (Annex 6, 7 & 8) | International — transport | Burning behaviour of bus/coach interior materials: horizontal & vertical burn, melting |
| EN 597 Part 1 & 2 | EU — mattresses | Ignitability of mattresses & upholstered bed bases: cigarette (1) & match (2) |
| NFPA 260 (clause 6.1) | USA — furniture | Cigarette-ignition resistance of upholstered-furniture components |
| California Technical Bulletin 117 | USA — furniture | Flammability (smoulder resistance) of upholstered furniture |
| FAR 25.853 | USA — aviation | Flammability of aircraft cabin interior materials |
| NF D 60-013 (AM18) | France — seating | Fire behaviour of furniture seating (French AM18 fire-safety regulation) |
| ÖNORM A 3800-1 | Austria | Reaction to fire of building / furnishing materials |
| ÖNORM B 3825 | Austria | Flame-resistance classification (schwerbrennbar) of flexible materials |

# Notes

* A few standards target adjacent product types — **EN 597** (mattresses), **FAR 25.853**
  (aircraft) and **FMVSS302 / R118** (vehicles) — but all are fire-performance tests and appear
  under the site's single Flammability filter.
* Per-collection fire ratings are recorded on each product concept's spec table; this file is the
  master taxonomy those values draw from.
