# Monteiro Fabrics — Internal Knowledge Bundle

Open Knowledge Format master bundle for **Monteiro Fabrics**. One file = one concept; the file
path is its identity; concepts cross-link to form a graph. This is the private source of truth;
the public `/okf/` bundle is the subset of concepts marked `visibility: public`.

> **Terminology:** "Collection" means three different things across Monteiro's systems (fabric line vs sector vs editorial). See [Terminology](/references/terminology.md).

Types used: Company, Brand, Product, Range, Service, Segment, Competitor, Persona, Channel,
ContentTemplate, Campaign, Objective, Initiative, Change, Playbook, Reference, Note.
