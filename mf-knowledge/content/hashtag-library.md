> connected. Build each post's set into the Notion planner's `Hashtags` field.

# How to build a set
- **Instagram:** ~8–15 tags = Core + Sector + a few Attribute/Design. Put them in the `Hashtags`
  field, not the caption body.
- **LinkedIn:** 0–3 relevant tags only (LinkedIn rewards restraint).
